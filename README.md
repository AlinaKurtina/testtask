# How to run the app:
## via GitHub pages (already built)
https://alinakurtina.github.io/testtask/
## via directory
1. Download and open the root directory.
2. Run 'npm install' in your code editor's terminal.
3. Run 'npm start' in your code editor's terminal.
4. Run 'npm run build' in your code editor's terminal.
# Project structure:
- 'assets' folder contains all the assets used in the project;
- 'src' folder contains source code for the project;
- 'src/css' folder contains all css files created and edited during project development (separared for easier workflow);
- 'src/js' folder contains all javascript files created and edited during project development (separared for easier workflow);
- 'dist' folder contains deploy-ready main .html, .css and .js files that are created off .css and .js files from the src folder for optimization purposes;
-project root folder contains tools configuration files used to build and deply the project.
